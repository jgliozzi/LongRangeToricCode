# LongRangeToricCode
Monte Carlo simulations of long range toric code at finite temperature: evidence for topological order and self-correcting quantum memory.

This repository contains code to simulate thermal dynamics in the long-range toric code, a system that has topological order at finite temperature. The simulations are performed in the magnetic sector, i.e. the Z-sector of the Hamiltonian, so thermal dynamics reduces to classical Monte Carlo sampling. The Hamiltonian is defined on an L x L square lattice with spins on links. The terms in the Hamiltonian are square Wilson loops, i.e. the products of Pauli-Z operators around the links of a square, with a coupling that decays as a power law with perimeter of the square.

Several properties of the finite-temperature phase are measured from these Monte Carlo simulations:

1. Memory properties, which involve heating a ground state and testing to see if the quantum information encoded in the ground state is preserved

2. Equilibrium properties, which involve cooling from infinite temperature to sample the Gibbs state at a finite temperature

## Requirements

Python 3 with `numpy`, `scipy`, `numba`, `joblib`, `pymatching`, `matplotlib`.

## Files

`longtoric.py` is the main file, and contains all the helper functions to define the model, its energies, time evolution using Metropolis sampling, and any important properties (like extracting anyon configurations from flipped links)
 
`pfail.py`  starts in the ground state of the toric code, evolves 200 Monte Carlo steps at each temperature, and saves final snapshots
 
`pfail_process.py` takes the snapshots generated by pfail.py and calculates the probability of  logical error at different temperatures, using MWPM

`tmem.py` calculates the memory time = first time that MWPM fails to recover initial logical state for smaller system sizes

`wilson.py`  calculates the thermal expectation values of contractible and noncontractible Wilson loops
 
`gen_mc.py` generates Monte Carlo snapshots of L x L systems at different temperatures and long-range exponents alpha. There is an option to generate the snapshots either by cooling from T = infinity or heating from T = 0. Also includes code to combine and compress raw data files after they are generated.

`specific_heat.py` calculates specific heat from Monte Carlo snapshots

`rg_decoder.py` runs RG decoder on Monte Carlo snapshots, cleans up anyons by coarse graining and returns anyon density at each step

`squareloop_plots.py` produces the plots used in the paper


## Parameters

- Alpha (long-range exponent) values used in paper: 1.8, 2.5, 4.0. 
- Temperature grids are set in `temps_list` (in `longtoric.py`)
- System sizes: L = 16, 24, 32, 40 for logical failure probability, specific heat, and noncontractible Wilson loops; 
			L = 8–20 for memory time; 
			L = 64 for contractible Wilson loops; 
			L = 128 for the RG decoder.
- Time unit: one Monte Carlo time step is 2 * L * L single-link flip attempts.
